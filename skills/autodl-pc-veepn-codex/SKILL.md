# AutoDL 网络、环境与 Codex 部署

由 Windows 电脑发起连接，让 AutoDL 指定程序沿独立反向隧道使用电脑上的认证代理。交付可实际使用的实例、日常脚本和中文验收记录。功能与设计原理见 [README.md（使用说明）](README.md)。

## 调查本次环境

先调查可读配置，向用户补充询问当前 SSH 命令、实例简称和 VeePN 连接状态中的缺失项。账号秘密通过用户自己的终端或官方页面输入。

优先复用电脑已有 GOST 工程，常见位置为 `D:\GOST\veepn-bridge`。每个新实例使用工程内独立的 `autodl-instances/<实例简称>/`（实例运行目录）。调查实际路径、端口、已有密钥和主机记录，以本次观察填写参数，保留既有实例配置。

## 部署流程

1. 读[网络部署](references/network.md)：先验证电脑侧代理，再严格核验主机身份和 SSH 认证，登录后只读盘点服务器，建立实例专属的回环反向隧道。
2. 读[个人环境与 Codex](references/environment-codex.md)：复用已有 Python/Conda（Python 环境管理工具），部署按需代理命令，用执行时核对过的官方安装器安装完整程序包，并保留可跟随升级的代理入口。
3. 读[验收与恢复](references/acceptance-recovery.md)：实测两端出口、网站、认证、环境恢复、升级和账号状态。需要 ChatGPT 登录时暂停依赖登录的验证，由用户在可见终端和官方页面完成授权，再继续模型请求及默认交互测试。
4. 交付本实例启动、停止、测试和登录脚本，以及中文使用说明和验收报告。每项检查记录实际执行时间、状态、观察值和后续动作。

先阅读本包脚本接口，再将辅助文件复制到实例运行目录，用实际路径和端口执行。配置、凭据及日志保存在本次运行目录或服务器私人主目录中。

## 操作约束

- 用户负责 VeePN 的连接、断开、切换和重新登录。保持支撑当前会话的联网连接；本任务沿 AutoDL 公网 SSH 连接执行。
- 代理限制在指定用户或进程范围内，服务器全局网络设置保持原状。电脑代理与远端监听保持回环地址，沿用已有共享代理与名称解析服务。
- 新建或替换密钥、改变认证方式、提权或涉及已有科研服务的调整，在说明影响并获得用户授权后执行；已有明确授权按本次范围继续。
- 保持严格主机公钥校验。首次或重建后变化，通过可信控制台或用户核对指纹；`ssh-keyscan`（收集主机公钥的命令）的结果用作待核验材料。
- GOST 保留认证。私人配置目录权限为 700，敏感文件为 600；凭据经已验证连接的标准输入传递，公开输出使用脱敏结果。
- 变更前备份。停止进程时同时核对本实例记录、程序路径、命令和创建时间，只管理本次创建的对应进程。
- 现有有效 ChatGPT 登录保持原样；新实例通过官方页面完成独立授权。个人环境包括命令路径、代理与 Codex 基础配置，现有项目和 Conda 环境继续保留。
