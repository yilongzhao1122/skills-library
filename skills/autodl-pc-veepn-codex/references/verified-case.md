# 实测记录与设计依据

2026 年 11 月 13 日，完成两台 AutoDL（云计算平台）实例的实际部署。公开记录保留环境、检查结果和处理方法，实例连接信息与原始日志保存在本地私人目录。

## 实际结果

| 项目 | 已有实例 | 新实例 |
|---|---|---|
| 系统 | Ubuntu 22.04（Linux 发行版） | Ubuntu 22.04.5 LTS（长期支持版） |
| Python | 复用已有 Conda（Python 环境管理工具）环境 | 复用已有 Python 3.12.3 |
| 电脑代理 | GOST 3.3.3（网络代理转发工具） | 复用同一已有代理程序 |
| 两端出口 | 同轮一致 | 同轮一致 |
| Google、GitHub、ChatGPT | HTTP（网页传输协议）200；CONNECT（建立代理隧道的方法）200；TLS（传输层安全协议）校验 0 | 同项全部通过 |
| 认证检查 | 省略认证时返回 407 | 同项通过 |
| Codex（编程助手）升级 | 官方完整安装从 0.168.0 升至 0.169.0 | 官方最新版本 0.169.0，再执行升级命令退出 0 |
| ChatGPT 登录 | 已有个人账号状态保留 | 用户在官方页面完成独立授权 |
| 模型请求 | 预期回答 `PCVPN_AUTODL_OK`，回合完成 | 同项通过 |
| 默认终端交互 | 预期回答 `PCVPN_TUI_OK` | 真终端启动默认完整界面，收到同一预期回答 |
| 配置保留 | 个人范围内变更并备份 | 原启动配置前缀和备份摘要核对一致，其他在运行通道保持运行 |

0.169.0 是测试当天的实际版本。后续部署由执行时的官方安装器解析版本，并重新验证。

## 形成的操作方法

完整程序包包含默认交互所用的辅助程序，官方管理目录提供升级识别信息。因此安装使用官方完整布局，外层代理入口和内部管理命令分别保存，内部通过当前发行版链接继续跟随升级。

新实例的 SSH（安全远程连接协议）默认路径较慢。调查当前物理网卡后，在该实例配置中验证源地址绑定，连接耗时约 0.74 秒，随后网站请求全部通过。每次部署都重新调查实际路径与地址。

新安装在用户授权前单独记录等待登录状态。官方授权完成后，整体健康检查全部通过。安装结构与账号状态分阶段验证，结果与当前操作阶段对应。

默认终端交互的增量刷新把回答拆成多次绘制。检查程序归一化控制序列与空白后，结合本次测试会话中的最终回答，确认收到 `PCVPN_TUI_OK`。本次终端观察和会话原文相互印证。
