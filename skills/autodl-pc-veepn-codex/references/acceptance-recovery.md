# 验收、日常使用与恢复

## 实际执行的检查

在本实例目录保存 `Test-AutoDL.ps1`（可重复运行的测试脚本），按照实际参数调用配套辅助程序。测试结果包含时间和是否为本轮执行的记录。

| 检查 | 观察值与判断依据 |
|---|---|
| 电脑代理 | 正确的 GOST（网络代理转发工具）进程、回环配置、认证后的网站访问与省略认证时的 407 响应 |
| 主机和隧道 | 严格 SSH（安全远程连接协议）主机校验；远端实际监听为本实例的 IPv4（第四版网际协议）回环地址 |
| 网络出口 | 两端同轮出口一致；Google、GitHub、ChatGPT 的响应状态、证书校验和耗时 |
| 凭据与目录 | 私人目录权限 700；敏感文件权限 600；凭据通过标准输入传递 |
| 个人环境 | 新 Bash（命令解释器）可找到命令；已有会话加载后可用；重复启停恢复原值与设置状态；单进程代理只影响目标子进程 |
| 完整安装和升级 | 官方完整包、真实路径和健康检查通过；实际执行升级后代理入口仍保留 |
| 账号 | 登录状态显示 ChatGPT 账号授权 |
| 模型请求 | 最小请求退出 0，收到预期回答与 `turn.completed`（回合完成事件） |
| 默认交互 | 分配 PTY（伪终端，用来模拟真实终端交互），使用默认完整界面和后台服务路径，观察到模型回答 |
| 已有环境 | 原配置备份、项目、登录与其他实例继续保留 |

首次部署完成全部检查。日常运行测试脚本会重新验证网络、环境、登录与本地健康状态，并分别列出此前保存的模型、交互和升级结果。使用 `-ModelTest`（重新测试模型请求与默认交互）或 `-UpdateTest`（重新执行升级）时，再执行相应项目，记录本轮结果。

服务器的 `test-codex.py`（模型请求测试）和 `test-codex-tui.py`（默认终端交互测试）由传送程序执行，使用私人状态目录下的空工作区。每种请求通常执行一次，结果文件和日志设为 600。

终端会增量刷新内容。交互检查先清理控制序列并归一化分段空白；必要时核对本次测试工作区对应会话中的最终回答，再判断结果。保留原始观察记录，校验通过后继续交付。

网站状态、传输连接和账号请求分别记录。遇到 403（服务端拒绝或挑战响应）时保留实际状态，再结合连接和模型结果定位；每项结果明确对应已执行的检查。

## 日常启动和停止

电脑连接 VeePN（虚拟专用网络软件），启动 AutoDL（云计算平台）实例，在 PowerShell（Windows 命令行工具）运行实例的启动脚本，再运行测试脚本。通过后，登录服务器直接运行 `codex`（编程助手命令），其他程序按需使用个人代理入口。

结束时退出需要联网的任务，在相应命令解释器恢复代理环境，再运行本实例停止脚本。共享代理和其他实例继续使用各自配置。电脑睡眠、断网、切换连接或实例停机后，恢复连接再重新启动和测试。

## 按层恢复

| 观察 | 下一步操作 |
|---|---|
| 电脑代理连接异常 | 核对共享代理程序、配置、回环监听和名称解析辅助程序的日志 |
| 认证返回 407 | 重新读取已有口令文件，核对请求参数和代理配置 |
| 地址可访问而域名解析异常 | 核对代理的名称解析路径，保留服务器全局设置 |
| 电脑正常而远端代理连接异常 | 核对本实例进程与错误日志，确认端口释放和监听后重新启动 |
| 反向转发端口被占用 | 识别占用者，复用经过验证的已有通道或分配其他端口 |
| SSH 较慢 | 检查当前实例地址、电脑应用分流和实际网卡，按实测选择本实例源地址 |
| 主机公钥变化 | 暂停连接，从可信控制台核验，再更新对应主机记录 |
| Codex 程序包或升级识别异常 | 核对真实入口、官方完整包和当前管理布局，保留外层代理入口 |
| 模型请求返回错误 | 按实际错误检查账号额度、模型权限、服务商配置与联网路径 |
| 新终端命令路径变化 | 核对启动配置、个人命令目录和实例存储状态 |

## 备份与恢复

先记录本次文件清单、备份、进程身份和启动配置标记区块。回滚时停止本实例自建隧道，逐项恢复本次改动；启动配置按标记区块处理，保留之后的用户修改与账号登录。

版本回滚沿用官方完整安装器和受支持的管理布局。公钥变动按本次准确添加的记录处理。最终说明列出实例停机、重建、端口和电脑地址变化后的恢复步骤，以及系统盘与数据盘的当前保留规则。
