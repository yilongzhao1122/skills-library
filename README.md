# skills-library（技能库）

我把实际工作中用过的 skill（供智能助手执行任务的技能）整理在这里。每个技能都有独立的说明和配套文件，便于按用途查找，也方便下次遇到同类任务时直接使用。

## 按用途查找

| 用途 | 技能 | 能完成的工作 |
|---|---|---|
| 云服务器与个人开发环境 | [AutoDL 网络、个人环境与 Codex 部署](skills/autodl-pc-veepn-codex/README.md) | 让 AutoDL（云计算平台）实例通过 PC（个人电脑）的 VeePN（虚拟专用网络软件）联网，配置个人代理命令，安装并验证使用 ChatGPT 登录的 Codex（编程助手） |

## 使用技能

先打开技能自己的说明页，确认使用场景和准备条件，再把整个技能目录放进所用智能助手的技能目录。以 Codex 为例，用户级技能通常放在 `~/.codex/skills/`，具体位置按当前客户端的设置确定。

调用时写明技能名称和本次任务参数。例如，AutoDL 部署技能需要实例当前的 SSH（安全远程连接协议）地址、实例简称，以及电脑上 VeePN 的连接状态。它会继续调查已有环境，按实际情况完成部署和验证。

每个技能目录中的 `SKILL.md`（技能执行说明）供智能助手读取；`README.md`（使用说明）介绍功能、原理和操作方法。配套脚本、模板和参考资料随技能一起保存。

## 收录方式

技能按独立目录放在 `skills/`（技能目录）下，首页按用途建立索引。新增技能时，可以从[说明模板](templates/skill-readme.md)起稿，按[收录流程](docs/adding-skills.md)整理文件。

功能描述统一使用中文，首次出现的专业英文词或缩写在后面附上中文解释。文字先讲清楚能完成什么、如何工作，再用 Humanizer（文字润色技能）梳理表达。具体约定见[写作规范](docs/writing-guide.md)。
